# قاعدة بيانات المكتبة الذكية (Supabase)

1. افتح **SQL Editor ← New query** في مشروع Supabase.
2. الصق محتوى `migrations/0001_init.sql` كاملاً واضغط **Run** (مرة واحدة فقط).
3. أنشئ الحسابات من **Authentication ← Users** كما في آخر الملف، ثم عيّن أول مدير.

يتضمن الملف: الجداول، صلاحيات الأمان (RLS)، دوال الاستعارة والإرجاع والتمديد والحجز،
حاويات التخزين (`covers` و`book-files`)، وبيانات أولية (4 أقسام و10 كتب).

كلمات المرور تُدار في Supabase Auth. إنشاء الحسابات وإعادة تعيين كلمة مرور حساب آخر
تحتاجان مفتاح الإدارة (`service_role`)، فتُنفَّذان لاحقاً في Edge Function ولا يوضع هذا المفتاح في التطبيق.
