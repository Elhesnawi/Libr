# المكتبة الذكية: المرحلة الثانية (كل الشاشات بدون API)

هذه النسخة تشغّل كل الشاشات بالكامل على بيانات محلية مؤقتة داخل التطبيق، بدون إنترنت وبدون Supabase.
ولا تحتاج إضافة أي حزمة جديدة.

## طريقة التركيب (3 خطوات)
1. افتح مجلد مشروعك (مثل `C:\devo\book`) واحذف المجلدين `lib` و `test` القديمين.
2. انسخ من هذا الملف المجلدات `lib` و `test` و `assets` إلى مجلد المشروع (وافق على الاستبدال).
   - ملف `pubspec.yaml` لا تغيّره، ويجب أن يبقى فيه تعريف `assets/images/`.
   - الحزم القديمة (dio و flutter_bloc و flutter_secure_storage) تبقى في الملف ولا ضرر منها، ولا يستخدمها الكود الجديد.
3. من الطرفية في مجلد المشروع:
   ```
   flutter pub get
   flutter run -d chrome
   ```

## حسابات التجربة (كلمة المرور 1234)
| الحساب | الدور | ماذا ترى |
|---|---|---|
| `user1` | مستخدم عادي | الرئيسية، البحث، استعاراتي، المفضلة، الإشعارات، اقتراح كتاب |
| `lib1` | موظف (أمين مكتبة) | لوحة الموظف: الكتب، الأقسام، الاستعارات، الباركود، الطلبات، الإعلانات، السجل |
| `admin` | مدير النظام | كل ما سبق + الحسابات والإحصائيات والتقارير |

أزرار الحسابات التجريبية تظهر في شاشة الدخول في وضع التطوير فقط (`kDebugMode`)، وتختفي في النسخة النهائية.

## ما الذي يعمل فعلاً، وما الذي هو محاكاة
يعمل بالكامل (على البيانات المحلية): الدخول والخروج وصلاحيات الأدوار، البحث العربي الذكي، الاستعارة (حد 3 كتب و14 يوماً)،
الحجز وإخطار الحاجز عند الإرجاع، المفضلة، الإشعارات، إضافة الكتب وتعديلها وحذفها، الأقسام، الاستعارات والتمديد،
طلبات الكتب والقبول والرفض، الإعلانات، سجل النشاط، إنشاء الحسابات وتغيير الأدوار، تغيير كلمة المرور،
الإحصائيات، والوضع الليلي.

محاكاة حتى نربط الخادم لاحقاً:
- **قراءة وتحميل الكتب الرقمية ورفع ملف PDF والغلاف:** تعرض رسالة فقط.
- **مسح الباركود:** المسح بقائمتين، وتُستبدل بالكاميرا (حزمة مثل `mobile_scanner`) لاحقاً.
- **تصدير PDF و Excel:** يسجل العملية فقط دون إنشاء ملف.
- **الحفظ:** البيانات في الذاكرة، فتعود إلى حالتها الأولى عند إعادة تشغيل التطبيق.

## شاشة التحميل
كل عملية تحتاج وقتاً (الدخول، الخروج، الحفظ، الحذف، الاستعارة، فتح صفحة، تبديل التبويب) تعرض شاشة بشعار الهيئة.
الدالة المسؤولة هي `withSplash` في `lib/widgets/loading_splash.dart`.

## هيكل الملفات
- `lib/services/library_store.dart`: كل البيانات والقواعد والصلاحيات (هنا يتم الربط بـ Supabase لاحقاً).
- `lib/models/`: النماذج.
- `lib/views/user/`: شاشات المستخدم. `lib/views/staff/`: شاشات الموظف والمدير.
- `lib/widgets/`: الودجتات المشتركة (الشعار، شاشة التحميل، بطاقة الترحيب...).
- `test/widget_test.dart`: اختبارات لقواعد المخزن. شغّلها بالأمر `flutter test`.
